AmiDrive - release history
==========================

Reporting bugs: give the version (in a Shell: Version AmiDrive) and attach
the log <drawer with the files>/.AmiDrive/AmiDrive.log (it holds no tokens).


0.3.10 (14.10.2026)
-------------------
- Window title: "OneDrive" with the version. One line below the bar
  ("Last check 15:12 no changes; Next at 15:55"), a lower window; while
  working the file name in the top line, amounts, speed and time below.

0.3.9 (14.10.2026)
------------------
- Buttons "Sync now", "Stop", "Quit": Stop stops the synchronisation (paused
  until "Sync now"), Quit ends the program; closing the window hides it.
  Tools menu: "AmiDrive: quit".
- The check result names only what changed, e.g. "20 deleted".

0.3.8 (14.10.2026)
------------------
- The drawer with the files always right below the AmiDrive window, as wide
  (also when its icon was there before, e.g. from the installer).
- Texts: "Last check 16:24 no changes", "Next at 16:27".

0.3.7 (14.10.2026)
------------------
- The AmiDrive window as wide as its buttons (the drawer below it too),
  shorter progress texts ("57% file", "3.8 MB/18.3 MB 150 KB/s ~2 min"),
  redrawn without flicker.

0.3.6 (14.10.2026)
------------------
- The AmiDrive window at the top left, the drawer with the files below it,
  as wide; narrower buttons close together, a smaller window.

0.3.5 (14.10.2026)
------------------
- The drawer with the files opens listing all files by name in a bigger
  window (a drawer icon is made if there is none).
- Smaller buttons; the AmiDrive window at the right edge of the screen.

0.3.4 (14.10.2026)
------------------
- Faster downloads: the ciphers fastest on a 68k (ChaCha20, AES-128 instead
  of AES-256) - about 20% faster from OneDrive.
- Smaller AmiDrive window, buttons "Sync now", "Stop", "Hide".
- AmiDrive TEST URL=... - download speed test (http and https).

0.3.3 (14.10.2026)
------------------
- AmiDrive window with the buttons "Synchronise now", "Stop AmiDrive" and
  "Hide"; double-clicking the "OneDrive" icon always opens it (with the
  drawer).

0.3.2 (14.10.2026)
------------------
- Progress window: what is going on, a bar with the percentage, the file,
  the speed and the estimated time left; between synchronisations the last
  result and the time of the next one. Tools menu: "AmiDrive: status".
- Double-clicking the "OneDrive" icon opens the drawer at once, also during
  a long synchronisation (it used to wait until the end), and shows progress.
- "AmiDrive: stop" works during a synchronisation.

0.3.1 (14.10.2026)
------------------
- Wrong Amiga clock: a window with the Amiga time and the Internet time and
  a button to set the clock (also the battery clock); option
  CLOCK=ASK|AUTO|NO (AUTO: set by itself at the start and once a day),
  command AmiDrive SETCLOCK, a clock question in the installer.
- The message about a rejected certificate suggests checking the clock.
- Colour icons in the GlowIcons style, a separate installer icon.

0.3.0 (14.10.2026)
------------------
- Installer (Install-AmiDrive): where to put the program and the files, the
  OneDrive folder, character set, interval, direction, icon, time zone and
  autostart.
- "OneDrive" icon on the Workbench: double-click opens the drawer, files
  dropped on it are copied and sent, commands in the Tools menu.
- Autostart from SYS:WBStartup.

0.2.0 (14.10.2026)
------------------
- Start from the icon (Tool Types), sign-in in a window on the first start.
- Background work, AmiDrive STOP, only one synchronisation at a time.
- Log .AmiDrive/AmiDrive.log.
- Fix: crash after signing in from the icon.

0.1.0 (14.10.2026)
------------------
- First version: sign-in with a device code, synchronisation both ways,
  conflicts without losing data.
